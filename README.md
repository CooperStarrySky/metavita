# Metavita

A study tool for learning the tree of life behind the Metazooa, Metaflora and Metamicrobia puzzles. One page with three tabs:

- **Practice**: guess the clade that groups a set of animals, plants or microbes.
- **Skeleton**: fill in or rebuild a pruned tree from the decks you've studied.
- **Tree**: browse the whole tree, with Wikipedia summaries and etymology.

Open it at https://cooperstarrysky.github.io/metavita/. Everything runs in the browser, and progress is saved locally.

Tree data comes from the NCBI Taxonomy. Summaries and pictures come from Wikipedia (CC BY-SA), with a link back to each article.
